# App Review notes for Open Limits 1.1 (build 6)

Paste into App Store Connect > version 1.1 > App Review Information > Notes.

---

Thank you for your feedback on 4.3. Version 1.1 changes the app's core idea so it is clearly different from other Screen Time apps:

1. Solve to unlock (new, the main feature). When an app's opens are used up, the only way to get another open (besides the emergency hold, which breaks your streak) is to solve maths problems: 3 in a row by default, a wrong answer starts the count again. Five levels (adding, times tables, two-digit numbers, percents and fractions, algebra), adjustable count and a daily cap. An optional mode asks for a problem before every open. As far as we know, no other app limiter on the App Store uses maths problems to earn opens. It fits our developer brand: MES (Math Easy Solutions) makes maths tutorials and calculators.

2. Weekly budgets (new). A limit can be a number of opens per week (Monday to Sunday) instead of per day, with "28 left this week, about 4 a day" shown on the shield.

3. Opens, not minutes, plus nudge messages read aloud or in a recorded voice (from version 1.0).

How to see it:
- Add a limit (any app, e.g. 1 open a day) on the Today screen, open the app once, and open it again: the shield shows "Solve maths for 1 more open". Tapping it posts a notification; tapping the notification opens the maths screen. Solve 3 problems and the app opens.
- Or: on the Today screen, a locked limit shows a "Solve maths for 1 more open" button that opens the same maths screen directly.
- Settings > Solve to unlock (maths) has the level, problems in a row and daily cap.
- The limit editor has a Per day / Per week switch.

Screen Time is used through FamilyControls (individual authorization), ManagedSettings and DeviceActivity with the Family Controls (Distribution) entitlement (approved Nov 15, 2026, request RVQW92853F). No data leaves the device.
