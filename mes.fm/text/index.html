Open text files, RTF and code in your browser

The MES Text Viewer opens any text-based file and shows it two ways. Reading view lays the text out like a page in a book: Markdown is formatted with headings and lists, RTF (rich text from WordPad and TextEdit) keeps its bold, italic, sizes, colours and tables, web pages are shown without their scripts, CSV spreadsheets become tables, and plain text gets comfortable line lengths with clickable links. Code view shows the exact text with line numbers and colours for more than 30 programming languages.

What you can do

  • Open a file, drop it on the page, paste it, or paste a link to one (GitHub, Google Docs, Google Drive and Dropbox links are turned into the file itself).
  • Read it aloud with every word highlighted, using the voices on your device.
  • Change the text size, font, width and look (paper, sepia, dark), or fill the whole window for reading.
  • Edit the text and download it again, or download it as plain .txt.
  • Fix odd characters by choosing another character encoding (old Windows files, Cyrillic, Japanese, Chinese, Korean).
  • Old e-texts and emails cut into short lines can be joined back into paragraphs.

Questions

Is my file uploaded?
No. It is read and shown by your browser. A file opened from a link is fetched by your browser too; only when the other website blocks that does mes.fm fetch it for you, without keeping a copy.
Which files work?
Anything that is text inside: .txt, .md, .rtf, .csv, .tsv, .json, .xml, .html, .log, .srt, .yaml, .ini and source code. Word files (.docx) open in the Word Viewer and PDFs in the PDF Editor; if you drop one here you are taken there.
Why do some letters look wrong?
The file was saved in an older character encoding. Open More and pick another one under Characters.
