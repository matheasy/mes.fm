MES Dark Mode

A setup is a mode plus brightness, contrast and colour tweaks. Make one for each purpose (day, night, reading) and switch in the toolbar popup. Changes save automatically. Each site can also be set to Dark, Light or Off from the popup (see “Sites with their own choice” below).

Mode

Make pagesDark makes light pages dark. Light makes dark pages light. System follows your computer's theme. Schedule is dark between two times. A page that already matches is left alone.

Toolbar button

Clicking the toolbar buttonSwitches the current tab between dark and its own colours with one click (the button shows a moon while the tab is dark, and its tooltip says why a page is dark), or opens the panel. With the switch, the panel is still one right-click away: right-click the button and choose “Open the Dark Mode panel”. The keyboard shortcut Alt+Shift+D always switches.
What the button changes“Only this tab” switches just the page you press it on. It stays while you keep using that site in that tab (reload, back / forward, links within the site) and is forgotten when the tab goes to another site, is closed, duplicated, opened from another page or restored after a restart, and after 30 minutes away. Other tabs are never touched. “All pages” turns every page dark, and pressing again puts every page back to normal (it changes the mode of the setup in use). The keyboard shortcut does the same.

Sites with their own choice

Saved for the site in every tab, on every visit, until you remove it. Set from the toolbar popup (“Site list”). The toolbar button and Alt+Shift+D never add sites here; they only switch the tab you are in. Change the shortcut at chrome://extensions/shortcuts (brave://, edge://).
