Bigger (or smaller) text on any website

A free browser extension by MES for Chrome, Brave, Edge and other Chromium browsers: the A− / A+ buttons from the top of mes.fm, for every site. Unlike the browser's zoom, only the text changes: pictures and layout stay where they are. The size is remembered for each site (or for all sites), from 50% to 300%.

Private by design: no accounts, no tracking, no network requests. The code is plain JavaScript you can read.

Install it (about a minute)

  1. Download the zip above and unzip it. You get a folder called mes-text-size. Keep it somewhere permanent (Documents is fine): the browser reads the extension from that folder.
  2. Open the extensions page: chrome://extensions in Chrome, brave://extensions in Brave, edge://extensions in Edge.
  3. Turn on Developer mode (a switch at the top right, or on the left in Edge).
  4. Click Load unpacked and choose the unzipped mes-text-size folder.
  5. Click the puzzle-piece icon in the toolbar and pin MES Text Size.

Chrome may show a "disable developer mode extensions" notice when it starts: choose Cancel / Keep. Brave and Edge usually do not. Until the extension is listed in the Chrome Web Store, updates are manual: download the new zip, replace the folder and press the reload arrow on the extensions page. Firefox is not supported yet.

How to use it

  • Click the toolbar icon and press A+ or A−, drag the slider or pick a preset. Every open page of that site follows at once.
  • Alt+Shift+Up / Down change the size, Alt+Shift+0 goes back to normal. Change the shortcuts at chrome://extensions/shortcuts.
  • Remember for this site or all sites. A site you have changed keeps its own size; sites you have not touched use the all-sites size (100% unless you set it).
  • In the settings: the step (5 to 25%), the all-sites size, and the list of sites that have their own size.

How it works, and its limits

Every piece of text on the page gets its own size (and line height) equal to what it had times your percentage. The original values are remembered, so any size, and 100%, is exact, and text that appears later (menus, comments, infinite scroll) is scaled as it arrives. Sizes that depend on each other (em, percentages, inherited text) are never scaled twice.

Because only text grows, a page built with fixed-height boxes can overflow or overlap at large sizes; if a site looks wrong, press Back to normal for that site. It cannot change browser pages (chrome://), the Web Store or the built-in PDF viewer. Text inside images or canvas is a picture, so it does not change.

Permissions

It runs on the pages you open (the browser words this as "read and change your data on all websites") because it has to change their text size. It does not read or send any page content. storage keeps your sizes; activeTab lets the popup show the current site.

Questions

How is this different from the browser's zoom?
Zoom (Ctrl +) enlarges everything, so wide pages get scrollbars and layouts change. This changes only the text, which keeps the layout and the pictures as designed.
Why did the size not change on one site?
Text drawn as images or inside a canvas or an embedded document from another site cannot be resized, and a site set to "Off" for everything is not affected. Reload the page after changing the size on a very unusual page.
Does it work with the MES site's own A− / A+ buttons?
On mes.fm those buttons already exist; using both would resize twice, so keep this extension at 100% on mes.fm.
Is it open source?
The whole extension is plain, readable JavaScript served from this site: content.js, shared.js, manifest.json.
