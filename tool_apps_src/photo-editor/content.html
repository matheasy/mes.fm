A free online photo editor with layers

MES Photo Editor runs entirely in your browser: pictures are never uploaded. Use layers, selections, the magic wand, a clone stamp, blur and sharpen, levels and curves, and add text labels, arrows, callouts, numbered steps and highlights to screenshots. Open PNG, JPEG, WebP, GIF, BMP, PSD and GIMP (.xcf) files, combine several images as layers, keep transparency, and export PNG, JPEG, WebP or a layered PSD.

Can I open Photoshop (PSD) files?
Yes. Layers, opacity, visibility and blend modes come across. Photoshop-only features (smart objects, layer styles, adjustment layers, live text) are flattened. You can also save a layered PSD.
Can I open GIMP (.xcf) files?
Yes, from GIMP 2.x and GIMP 3, including 16-bit and 32-bit images (shown in 8-bit), grayscale and indexed ones. Layers, layer groups, layer masks, positions, opacity, visibility and most layer modes come across; text layers open as pixels with the text as the layer name. GIMP's live filters and the few layer modes this editor does not have (for example Addition or Grain merge) are listed when the file opens. Drop an .xcf onto an open image to add it as a group of layers. File → Save as GIMP file writes an .xcf GIMP can open.
How do I make a background transparent?
Choose the Magic Wand, click the background, press Delete, then export as PNG or WebP. For soft edges use Adjust → Make a colour transparent.
How do I add labels and arrows to a screenshot?
Use the Text tool with its Background box option for labels, and the Shapes tool for arrows, boxes, callouts, numbered steps, highlights and blur/hide areas. Each lands on its own layer so you can move or delete it later.
Is my work saved?
It is auto-saved in this browser while you work, so you can restore your last session after a reload. Press 💾 Save project (Ctrl+S) to keep a file with all layers, groups and comps that you can open again later. File → Where are my images? shows where each layer came from and lets you clear the autosave.
Can it open and save files in a folder on my computer?
Yes, in Chrome and Edge on a computer: File → Connect a folder lists the pictures in a folder, adds them as layers, saves into it and can move a picture to another folder. Brave has this switched off: turn on brave://flags/#file-system-access-api and relaunch. Safari and Firefox can open a folder read only; saving there goes to your Downloads folder.
Does it work on a phone or tablet?
Yes, with touch and pen support (pinch to zoom, two fingers to pan). A larger screen is more comfortable for detailed work.
How do I convert many files at once?
Use the Bulk Image Converter to turn a whole folder of PNG, JPEG or WebP files into another format in one go.
