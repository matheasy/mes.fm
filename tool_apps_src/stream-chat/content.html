Your YouTube, Twitch and Odysee live chats in one window, Super Chats, stickers, memberships, bits, subs and tips included. Nothing to install: the page reads each chat directly. It finds your live (or scheduled) stream by itself, so just leave it open.

Use it in OBS

  1. Chat panel: in OBS choose Docks → Custom Browser Docks…, name it All Chats, paste this address and press Apply: https://mes.fm/stream-chat/dock
  2. On screen: in your scene add a Browser source, width 1920, height 1080, with this address: https://mes.fm/stream-chat/overlay It stays empty until you click a message in the OBS chat panel; that message then pops up on stream (click it again, or Take off screen, to remove it). To also show the latest messages on stream, use https://mes.fm/stream-chat/overlay?chat=1
  3. The panel and the overlay have to be in OBS together: clicking a message on this page in your normal browser does not reach OBS.

The panel remembers its own channels (⚙ in the panel). Out of the box it reads YouTube @mestruth and @mes, Twitch matheasysolutions and Odysee @mestruth: change them for your own channels.

How it works

YouTube: mes.fm asks YouTube for the channel's live page and then reads the chat the same way YouTube's own pop-out chat does, every few seconds. No YouTube account, API key or permission is needed, and only public chat is read.

Twitch: the page joins the channel's chat as an anonymous viewer, the way Twitch's own chat works when you are logged out, so messages arrive instantly.

Odysee: the page looks up the channel's current livestream and listens to its comment feed, with a check every 20 seconds in case a message is missed.

X (Twitter): not included yet. X has no public chat feed, so it would need a small MES browser extension that reads the X chat page; keep X's chat open next to this until then.

Questions

Can I reply from here?
Not yet: this window is for reading. Reply in each platform's own chat.
Are Super Chats shown?
Yes. Super Chats and Super Stickers show in their colour with the amount, as do new and gifted memberships, Twitch bits, subs, gift subs and raids, and Odysee tips. "$ Tips only" hides everything else, and the footer adds them up for the session.
Does it save the chat?
No. Messages live in this tab only and are gone when you close it. Settings (which channels, text size) are saved in this browser.
Why do some messages arrive a few seconds late?
YouTube chat is checked every few seconds (YouTube says how often); Twitch and Odysee are instant.
