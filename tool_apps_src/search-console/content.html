AI search

Drop the export files here or CSV, the ZIP Search Console downloads, or an Excel (.xlsx) file. Several at once is fine. Nothing leaves your browser until you press Save.
How to export them

Google: Search Console → the mes.fm property → Performance → Generative AI (Search) → choose the date range (e.g. Last 16 months) → Export → Download CSV. Drop the ZIP as it is (it holds Dates, Pages, Countries and Devices). Google has no API for this report.

Bing: Bing Webmaster Tools → mes.fm → AI Performance → choose the range → Download all (or the Download button above each table: the citations chart, Grounding queries, Pages). Bing has no API for this report.

Import again whenever you like: days are added or replaced by date, so a new 3-month export does not wipe the older months; the tables (pages, queries, countries, devices) are replaced by the newest export.
