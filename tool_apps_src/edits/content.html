    💾 Backups, moving devices and Telegram import

    The list lives on mes.fm (behind the same password as /ads), so every phone and computer that knows the password sees the same list. This browser also keeps the last copy it loaded, so you can still read it offline. Extra copies, in case something goes wrong on the server:

    1. A file

    Restoring adds back what is missing and keeps what you have (an item changed later wins). Nothing is deleted.

    2. Hive, encrypted

    Saved as one custom_json on your own account. With the 🛡 passphrase lock it is AES-256-GCM with a key made from your passphrase (PBKDF2, 600,000 rounds), which quantum computers can't break; no memo key is involved. Anyone can see that a save exists, when, and its size, but not the text. Lose the passphrase and nobody can open it, so write it down. Very long lists (more than about 150 KB packed) are too big for one save.
