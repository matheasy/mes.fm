How the video converter works

AVI with H.264: copied, not re-encoded
Screen recorders such as Bandicam, OBS and many cameras save AVI files whose picture is already H.264, the same video format MP4 uses. For those the converter does not touch the picture at all: it reads the AVI itself, takes every frame as it is and packs it into an MP4. That is why a long recording converts in seconds, with exactly the same picture quality. MP3 or PCM sound is turned into AAC (the sound MP4 editors expect); AAC sound is copied. It reads files of any size, including the OpenDML AVIs over 1 GB, and with “Save into a folder” the result is written as it is made.
Everything else: ffmpeg in your browser
MKV, WMV, FLV, MPG, MOV, WebM and AVIs with other codecs are read by ffmpeg compiled to WebAssembly (ffmpeg.wasm). It downloads once (about 31 MB) the first time you need it. When the picture is H.264 it is copied again; otherwise (WMV, MPEG-2, DivX, VP9 ...) it is re-encoded with x264, which is slower: count on a few minutes per minute of HD video. ffmpeg in a web page keeps the result in memory, so files up to about 1.5 GB are safe there.
Why MP4 for Camtasia?
Camtasia, Premiere, DaVinci Resolve, PowerPoint and phones read MP4 with H.264 picture and AAC sound everywhere. Older AVI, WMV and FLV files often import without sound, out of sync or not at all. Converting first fixes that.
Names
Each file keeps its name: Lesson 3.avi becomes Lesson 3.mp4. Download the files one by one, all at once as a ZIP, or let the page write them straight into a folder you choose (Chrome, Edge and Brave with the File System Access API turned on).
Brave: “Save into a folder” is off
Brave turns off the File System Access API. Open brave://flags/#file-system-access-api, set it to Enabled and restart Brave. Without it the results are kept in memory and downloaded.

Is it private?

Yes. Your videos are read and converted by your own browser and never sent anywhere. The only downloads are the small open-source libraries (mp4-muxer) and, for formats that need it, ffmpeg.wasm.
