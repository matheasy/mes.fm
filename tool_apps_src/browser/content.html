Recommended browser extensions & apps

Free add-ons that make the web faster to use. The extensions work in Chrome, Brave, Edge and other Chromium browsers: open the link, then press Add to Chrome (Brave and Edge install from the same page).

  • Video Speed ControllerSpeed any HTML5 video up or down (YouTube, Rumble, Odysee and most other sites) from 0.1x to 16x with keyboard shortcuts.
  • Volume BoosterTurn up the audio of a quiet video or tab above the browser's normal maximum.
  • Read Aloud: Text to SpeechReads the page you are on out loud in natural voices, highlighting as it goes.
  • Read Aloud for AndroidThe same text-to-speech reader as an Android app.
  • Archive PageSave a copy of any web page to an archive in one click, so it can still be read if the original disappears.
