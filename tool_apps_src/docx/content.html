Open, read and edit Word documents online

This viewer opens Microsoft Word .docx files right in your browser, laid out page by page like Word shows them: fonts, colours, tables, pictures, headers and footers, footnotes, lists, comments and tracked changes. Open several files at once and switch between them with the tabs. Nothing is uploaded: the file is read by your own browser, so it works for private letters, contracts and school work.

What can it do?

View
Page layout view with zoom, fit to width, a dark-paper option, Fill window and full screen. The Outline lists the headings so you can jump around a long document.
Find
Search the whole document, with match case and whole words. In Edit you can also replace one match or all of them.
Info
Word and character counts (with and without spaces), paragraphs, pages, reading and speaking time, the document properties (title, author, dates, the app that made it), page size and margins, and how many tables, pictures, comments and changes it has.
Comments and changes
Comments are listed with their author and date and marked in the text (hover the speech bubble). Tracked changes are shown as insertions and deletions. Both can be switched off.
Pictures
Every picture inside the document, ready to download one by one or all together as a ZIP.
Print and PDF
Print / PDF opens your browser's print window with just the pages; choose “Save as PDF” to make a PDF. You can then sign or annotate that PDF in the PDF Editor.
Edit
Edit turns the document into a simple editable page: type, make text bold, italic or underlined, add headings, lists, links, pictures and tables, then download a new .docx that Word, Google Docs and LibreOffice open. You can also save it as a web page, Markdown or plain text.

What does editing keep, and what does it lose?

Editing keeps the words, headings, bold / italic / underline / strikethrough, superscript and subscript, bullet and numbered lists, links, tables and pictures. It does not keep the exact page design: fonts, font sizes and colours, line spacing, page breaks, columns, text boxes and shapes, headers and footers, page numbers, footnotes, comments, tracked changes, fields such as a table of contents, and exact picture sizes are simplified or dropped. The saved file uses clean standard Word styles and keeps the original page size and margins. Your original file is never changed: Download → Original file always gives it back exactly. For documents with a complex layout, use View, Print / PDF, or edit in Word itself.

Questions

Can I open an old .doc file?
No. Only the modern .docx format (Word 2007 and later) can be read here. Open the .doc in Word, LibreOffice or Google Docs and save it as .docx first. .docm, .dotx and .dotm files open too.
Why does a page break fall in a different place than in Word?
Pages are laid out by your browser, not by Word, so line and page breaks can differ slightly, especially with fonts you do not have installed. Page breaks Word saved in the file are used where they exist.
Is my document uploaded anywhere?
No. The viewer and the libraries that read Word files run inside your browser. If you tick “Remember files I open here”, recent files are kept in this browser's own storage on this device, and you can forget them at any time.
Does it work on a phone?
Yes. Open a file from your phone's Files app; the page fits the screen width, and you can zoom in.
