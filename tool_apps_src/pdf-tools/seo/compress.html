Compress a PDF to make it smaller

Reduce the size of a large PDF so it is easier to email or upload. Choose a level and press Compress PDF; you see exactly how much smaller the result is.

  • Light rewrites the file more compactly and keeps the text selectable. It often saves little, because most of the weight is usually pictures.
  • Medium turns each page into a 150 dpi picture. A good balance for scans and photo-heavy files.
  • Strong uses 100 dpi and lower quality for the smallest file that is still readable on screen.

Why is my PDF so big?

Most large PDFs are made of high-resolution scans or photos. Text and vector drawings are tiny by comparison. If the result is not smaller, the original was already compact, and the page says so rather than handing you a bigger file.

To trim the page count first, use Split PDF or Organize PDF to drop pages you do not need.

Questions

Will compressing lose quality?
Medium and Strong re-save each page as a JPEG picture, so fine detail is reduced and text is no longer selectable. Light keeps everything as it is.
How can I keep the text selectable and still get a smaller file?
Use Light, or delete unneeded pages with Organize PDF.
Are my files uploaded anywhere?
No. Everything happens inside your browser, using your own device. Your files never leave it, so it is safe for contracts, IDs and tax papers.
Is there a limit on file size or number of files?
No sign-up and no watermark. Very large files are limited only by your device's memory.
Does it work on my phone?
Yes, in any modern browser, though a computer is more comfortable for many pages.
