Open, view and edit Excel files online

This viewer opens spreadsheets right in your browser: Excel .xlsx, .xlsm and older .xls files, LibreOffice .ods files and .csv / .tsv text files. Every sheet gets a tab at the bottom, with column letters and row numbers like Excel. It stays fast with big files (a hundred thousand rows or more), because only the cells on screen are drawn. Nothing is uploaded: the file is read by your own browser, so it is fine for budgets, marks and private lists.

What can it do?

View
Numbers, dates and percentages in the file's own formats, fill colours, wide columns you can drag wider or narrower, and a header row that stays at the top. Select cells with the mouse, a finger or the keyboard; the status bar shows the sum, average and count of a selection.
Formulas
The formula bar shows a cell's formula; the value comes from the file, as Excel last calculated it. When you change a number, the formulas that use it are worked out again: + − × ÷ ^ %, & to join text, comparisons, cell references and ranges (also on other sheets), and SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, ROUND, IF, ABS, SQRT, plus AND, OR, NOT, IFERROR, PRODUCT, MOD, INT, ROUNDUP, ROUNDDOWN, POWER, LEN, UPPER, LOWER, TRIM, CONCAT. A formula with any other function (VLOOKUP, for example) keeps the value saved in the file and is marked, so you know it was not worked out again.
Edit
Type into a cell or the formula bar, paste a block of cells from Excel or Google Sheets (and copy back), insert and delete rows and columns (formulas follow the cells), add and rename sheets. Undo and redo everything.
Find, sort and filter
Find any text in the sheet. Sort by a column or filter the rows (contains, equals, greater than, empty ...): this only changes what you see, never the data, and Clear brings the rows back in their own order.
Save
Save as .xlsx (every sheet, with formulas and number formats), .ods, or the current sheet as .csv or .tsv. Print / PDF prints the current sheet; choose “Save as PDF” in the print window to make a PDF.

Questions

Is my spreadsheet uploaded anywhere?
No. The page and the open-source library that reads spreadsheets run in your browser. If you tick “Remember files I open here”, recent files and your unsaved edits are kept in this browser's own storage on this device, and you can forget them at any time.
What is kept when I save as .xlsx?
Every sheet, the values, formulas, number formats and column widths. Charts, pictures, pivot tables, conditional formatting, comments and most cell styles (fonts, borders, colours) are not written back, so keep your original file; Save → Original file always gives it back exactly.
Why does a formula show a small corner mark?
It uses a function this page cannot calculate. It shows the value Excel saved in the file, which may be out of date after you change the cells it uses. Open the saved file in Excel, LibreOffice or Google Sheets to recalculate it.
Does it work on a phone?
Yes. Open a file from your Files app, scroll the grid with your finger, tap a cell to select it and tap it again (or press Edit) to change it.
Can it open password-protected files?
No. Remove the password in Excel first (File → Info → Protect Workbook).
