Questions

			
Why do I see only some fonts?

			
The page lists only fonts your browser can actually draw. A website cannot read your font folder, so it asks the browser, font by font, whether each name is really installed. Press Add 80 popular Google Fonts for a large, free set that works on every device, or add a font file you own.

			
Will the PNG look the same on another computer?

			
Yes: the PNG is a picture, so it looks exactly like the preview. The CSS only looks the same where that font is available, so for websites use a Google Font or host the font file yourself.

			
How does the picture matcher work?

			
It turns your picture into black and white, crops to the ink, shrinks it to a small grid, does the same for your words in each font, and compares the shapes (and the proportions of the text). It is a simple, honest comparison, not an AI: it works well for clear, straight text and fonts it can draw. For a font you do not have, try the other identifiers listed on the page.

			
Is it private?

			
Yes. Your text, pictures and favourites stay in your browser (favourites are saved in this browser only). The only network request is the Google Fonts download you start yourself.
