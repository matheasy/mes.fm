## Summary (from the manifest, max 132)

Make the text on any website bigger or smaller (A- / A+) for this tab, this site or every site. Free, private, no tracking.

## Description

Make the text on any website bigger or smaller without zooming the whole page. Pictures and layout stay as they are; only the text changes size.

What it does
• A- / A+ buttons and quick sizes from 50% to 300%.
• Change the size for this tab only, this site (all its tabs) or every site.
• Keyboard shortcuts: Alt+Shift+Up / Down, Alt+Shift+0 for normal.
• Works on pages that load more text as you scroll.

Free, no ads, no account and no tracking: it collects no data and sends nothing anywhere. Made by MES (mes.fm). Works in Chrome, Brave, Edge and other Chromium browsers.

## Permission justification: activeTab

Lets the popup show and change the size of the tab the person is on.

## Permission justification: Host permission (content script on all sites)

The text size applies to any website the person chooses, and has to be applied as the page loads, so the content script runs on every page. It only changes font sizes and sends nothing anywhere.
