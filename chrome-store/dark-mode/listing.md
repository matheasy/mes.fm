## Description

Dark mode for any website, or light mode for sites that are too dark. One click on the toolbar button switches the tab you are on; click again to go back.

What it does
• Smart invert: pages turn dark while photos, videos and canvases keep their real colours.
• Per tab by default, or per site (Auto / Dark / Light / Off), or every page.
• Modes: manual, always dark, always light, follow the system theme, or a schedule (for example 8 pm to 7 am).
• Brightness, contrast, sepia and greyscale sliders.
• Pages already dark are detected and left alone; keyboard shortcut Alt+Shift+D.

Free, no ads, no account and no tracking: it collects no data and sends nothing anywhere. Made by MES (mes.fm). Works in Chrome, Brave, Edge and other Chromium browsers.

## Single purpose

Show websites in dark mode (or light mode), per tab, per site or for all pages, with brightness and sepia adjustments.

## Permission justification: storage

Saves the person's mode, per-site choices and slider values.

## Permission justification: activeTab

Lets the toolbar button switch the tab the person clicked it on.

## Permission justification: contextMenus

Adds 'Open the Dark Mode panel for this site' to the toolbar button's right-click menu.

## Permission justification: scripting

After an install or update, re-adds the dark-mode style to tabs that are already open so they don't need a reload.

## Permission justification: Host permission <all_urls> (content script on all sites)

Dark mode has to be applied before a page first paints, on whatever site the person visits, or every page flashes white. The script only adds or removes one stylesheet and checks how light the page is; it reads no page content and sends nothing anywhere.
