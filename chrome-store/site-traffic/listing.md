## Description

How popular is the website you are on? MES Site Rank shows its public Tranco rank (a research ranking built from several traffic sources), a rough monthly-visits range worked out from it, and whether the rank is climbing or falling.

What it does
• Rank, tier (Top 1k, Top 1 million ...) and a 30-day rank line in the popup.
• A rough visits range, clearly labelled as an estimate.
• Optional badge with the rank on the toolbar icon for every site you visit (off by default).
• "Full report" opens mes.fm/site-traffic: domain age, hosting, archive history and more.

Free, no ads, no account. Only the site's domain name (never the full address) is sent to mes.fm for the lookup. Made by MES (mes.fm). Works in Chrome, Brave, Edge and other Chromium browsers.

## Single purpose

Show the public Tranco popularity rank and rank trend of the website in the current tab.

## Permission justification: storage

Saves whether the badge is on and caches rank answers for 6 hours.

## Permission justification: activeTab

Reads the domain of the tab the person clicked the extension on, to look up its rank.

## Permission justification: Host permission https://mes.fm/*

The rank lookup service (mes.fm/api/site-traffic) that returns the Tranco rank for a domain.

## Permission justification: Optional permission: tabs

Asked only if the person switches on the toolbar badge: reads the domain of each tab they visit so the badge can show its rank.

## Data usage

Tick 'Web history' (domain names of sites the person looks up, or visits with the optional badge on, are sent to mes.fm to get their rank; not stored or linked to the person). Then tick the three certifications.
