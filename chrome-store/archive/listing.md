## Description

Save a copy of the page you are on before it changes or disappears. One click opens the archive sites you choose with the page already filled in.

What it does
• Save a new copy on the Wayback Machine (Save Page Now), archive.today, Ghostarchive, Megalodon and more.
• Find copies that already exist: newest Wayback copy, the Wayback calendar, archive.today's newest copy, Arquivo.pt.
• Right-click any page or link: "Archive this page / link". Shortcut Alt+Shift+A.
• Retries archive.today on its other addresses when it is busy.
• Send the page to ArcHive (Hive blockchain) for a permanent copy, signed by you on the ArcHive page.
• Add your own archive sites.

Free, no ads, no account and no tracking. The page address goes only to the archive sites you pick; nothing is sent to MES. Made by MES (mes.fm). Works in Chrome, Brave, Edge and other Chromium browsers.

## Single purpose

Save a copy of the current page (or a link) on web archive sites such as the Wayback Machine and archive.today, or find existing copies.

## Permission justification: storage

Saves which archive sites the person ticked and any sites they added.

## Permission justification: activeTab

Reads the address of the tab the person clicked the extension on, to archive that page.

## Permission justification: contextMenus

Adds 'Archive this page' and 'Archive this link' to the right-click menu.

## Permission justification: scripting

For ArcHive only: when the person chooses it, reads the current page's text in that tab and hands it to the ArcHive page they opened.

## Permission justification: webRequest

Observes (never blocks or changes) the archive.today save tabs the extension opened, so a 429 'too busy' answer can be retried on the site's next address.

## Permission justification: Host permissions (archive.ph / .is / .today / .md / .vn / .li / .fo, dhenz14.github.io)

archive.today addresses: needed to see the status of the save tabs for the retry above. dhenz14.github.io: the ArcHive page the page text is handed to when the person chooses ArcHive.
